Мой первый проект на Python — консольный Таск-Менеджер с сохранением задач в JSON.

## Возможности

- Добавление задач
- Просмотр списка задач
- Удаление задач
- Отметка задач выполненными
- Изменение приоритета (высокий / обычный / низкий)
- Редактирование названия задачи
- Статистика (всего / выполнено / осталось)
- Сортировка по алфавиту, статусу и приоритету
- Поиск по названию
- Автосохранение в файл `tasks.json`

## Как запустить

1. Установи Python 3.10 или новее.
2. Скачай файлы `tasks.py` и `tasks.json` в одну папку.
3. Открой терминал в этой папке.
4. Запусти:
```
python tasks.py
```


## Технологии

- Python 3
- JSON (модуль `json`)
- ООП (классы, наследование, абстракция)
