# Task Manager

Мой проект на Python, представляющий собой два независимых приложения для управления задачами: консольную версию и полноценное веб-приложение на Flask. Данные в обоих случаях сохраняются в файл `tasks.json`.

## 🖥️ Версия 1: Консольный менеджер `tasks.py`

Первая версия проекта, написанная на чистом Python. Работает прямо в терминале.

### Возможности

- Добавление задач
- Просмотр списка задач
- Удаление задач
- Отметка задач выполненными
- Изменение приоритета (высокий / обычный / низкий)
- Редактирование названия задачи
- Статистика (всего / выполнено / осталось)
- Сортировка по алфавиту, статусу и приоритету
- Поиск по названию
- Автосохранение в файл `tasks.json`

(Также была скомпилирована версия в .exe для запуска без установки Python)

## Как запустить

### Консольная версия:
1. Установи Python 3.10 или новее.
2. Скачай файлы `tasks.py` и `tasks.json` в одну папку.
3. Открой терминал в этой папке.
4. Запусти:
```
python tasks.py
```
## 🌐 Версия 2: Веб-приложение `app.py` + `templates/` + `static/`

Современная веб-версия проекта на Flask с динамическим интерфейсом.

## Возможности

- Удобный веб-интерфейс с темной темой.

- Асинхронное добавление и удаление задач (без перезагрузки страницы благодаря Fetch API).

- Интерактивное изменение статуса и приоритета прямо на карточке задачи.

- Генерация уникальных идентификаторов (UUID) для каждой задачи.

- Умная обработка ошибок сети: если сервер недоступен, интерфейс откатывает изменения и сообщает об ошибке.
